# Pokémon Legends Z-A – Mods Collection

Curated gameplay, QoL, graphics, and item cheats for Pokémon Legends Z-A. These are organized for Eden Nightly (TID: 0100F43008C44000) and sourced from public forums. Enable selectively and avoid conflicts (e.g., multiple speed/FPS patches at once).

- Mod root: `0100F43008C44000/`
- Total mods: 147
- Tools in this repo:
	- `count_mods.py` – print a quick count of folders by category
	- `split_mods.py` – help split large cheat files into per-mod folders

## Install
1) Open Eden Nightly
2) Right-click the game > Open Mod Folder
3) Download the latest release ZIP of this repo [here](https://github.com/borgox/Pokemon-Legends-Z-A-Mods/releases/tag/release)
4) Extract the ZIP contents into the mod folder

Notes:
- Eden Nightly: https://github.com/pflyly/eden-nightly
- Not all mods are tested; toggle one at a time when uncertain.
- Prefer one variant per feature (e.g., choose a single “Game Speed” or “FPS” mod at a time).
